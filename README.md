# INTENT_v2.0

### Internship & Job Management Platform

**INTENT_v2.0** is a full-stack web application designed to connect **students and companies** through a centralized platform for internships and job opportunities.

It allows students to build professional profiles, discover opportunities, apply for jobs/internships, while companies can create their profiles, post opportunities, and manage applications.

---

## 🚀 Features

* 🔐 User Authentication & Authorization
* 👤 Role-Based Access Control
* 👨‍🎓 Student Profile Management
* 🏢 Company Profile Management
* 🎓 Internship Posting & Applications
* 💼 Job Posting & Applications
* 📩 Application Management & Tracking
* 🔍 Browse and Search Opportunities
* 📱 Responsive User Interface

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/INTENT_v2.0.git
cd INTENT_v2.0
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
